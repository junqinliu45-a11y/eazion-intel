## 结论

这只是单一材料的首轮基准，不足以决定长期路由。

当前路由建议

1. DeepSeek Web Search 负责低成本发现公开链接和热点线索。
2. 平台 API、Apify 或公开网页抓取负责得到真实原始数据。
3. gpt-6.1-terra 负责把原始数据转成统一 JSON，做 URL 去重、字段缺失检查和日常轻量摘要。
4. claude-sonnet-5-5 只处理已经筛选的竞品批次，用于解释内容机制、用户张力和证据边界。
5. gpt-6-sol 只在两个模型结论冲突、价格/规格变化或高价值竞品发生变化时复核。

模型不能凭空补齐被平台限制的数据。帖子互动、历史价格、私密社群、登录后评论、广告消耗等字段必须来自平台授权 API、合规采集服务或人工核验。

所有后续运行必须按 [交接规范](../README.md) 输出 Markdown 和 JSON，并带原始 URL、抓取时间、可见指标和数据缺口。
